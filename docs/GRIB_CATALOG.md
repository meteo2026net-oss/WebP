# فهرس بيانات GRIB للمنتجات AND / FMD / FPD / FSD

تضيف هذه الأداة جرداً محلياً للملفات التي ينزلها التطبيق من WMO Support. وهي مصممة لمجموعات كبيرة (17 GiB أو أكثر) وتقرأ الملفات على دفعات صغيرة، ولا تحمل الملف الكامل إلى الذاكرة.

## التشغيل على Windows

من جذر المستودع:

```powershell
$env:PYTHONPATH = "src"
python -m ecmwf_collector.tools.catalog_grib "E:\\ECMWF\\downloads" --output output/grib_catalog.json
```

لجرد البنية والبصمات فقط، من دون فك بيانات الرسائل عبر ecCodes:

```powershell
python -m ecmwf_collector.tools.catalog_grib "E:\\ECMWF\\downloads" --no-metadata
```

## ما الذي ينتجه؟

- إجمالي عدد الملفات والحجم بالبايت وGiB.
- إحصاءات مستقلة للبادئات AND وFMD وFPD وFSD.
- SHA-256 لكل ملف، مع ربط النسخ المتطابقة بأول ملف مطابق بدلاً من احتسابها كبيانات فريدة.
- فحص إطار GRIB1/GRIB2 وعدد الرسائل وخاتمة الرسالة.
- عند توفر ecCodes: رموز المتغيرات وأسماؤها ووحداتها ومستوياتها وأوقات الصلاحية UTC.
- ملف JSON قابل للاستخدام لاحقاً في واجهة التطبيق أو قواعد البيانات.

تُستثنى ملفات `.part` و`.invalid` و`.tmp` والملفات غير المعروفة، كما لا تُعدّل الأداة الملفات الأصلية ولا تحذف النسخ المكررة.

## ملاحظات تشغيلية

- حساب SHA-256 يقرأ كل بايت من الملفات، لذلك قد يستغرق وقتاً مع 17 GiB أو أكثر؛ الذاكرة المستخدمة تبقى محدودة بحجم كتلة القراءة (4 MiB).
- لا ترفع ملفات WMO المقيدة أو تقريراً يتضمن مسارات محلية حساسة إلى مستودع عام. شغّل الأداة محلياً واحتفظ بـ `grib_catalog.json` على جهازك.
- سلامة الإطار لا تعني أن كل قيم الحقل قابلة للفك أو أن المتغير معروف علمياً. يلزم ecCodes وجداول التعريف المناسبة، ثم اختبار التحويل والعرض.
- لا تحذف ملفات GRIB الأصلية بعد إنشاء طبقات الخرائط؛ تبقى هي المرجع العلمي الأساسي.
