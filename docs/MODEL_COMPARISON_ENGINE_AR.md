# محرك مقارنة النماذج العددية — المرحلة 9

## النطاق المنفذ

يوفر `ecmwf_collector.model_comparison` مقارنة حسابية أولية لحقول شبكية محمّلة
في الذاكرة، مع اختيار نموذج مرجعي صريح وحساب Bias وMAE وRMSE والارتباط،
ومقاييس الهطول POD/FAR/CSI عند تحديد عتبة.

## حواجز السلامة العلمية

- يجب أن تتطابق هوية المتغير والمستوى وقيمة المستوى ووحدته ووقت الصلاحية.
- يجب أن تتطابق هوية الشبكة وشكل المصفوفة؛ لا توجد إعادة إسقاط أو استيفاء ضمني.
- تحويل الوحدات محدود بقائمة صريحة؛ الوحدات المجهولة أو الملتبسة مرفوضة.
- تُحسب المقاييس على الخلايا finite المشتركة فقط، ويُعاد عددها وعدد القيم المفقودة.
- الإشارة معرفة بوضوح: المرشح ناقص المرجع. الارتباط غير معرف عندما تكون العينة
  صغيرة أو ثابتة التباين.
- عتبة الهطول تستخدم شرط `>=`، وتُحسب contingency scores من الخلايا المشتركة.

## الحدود الحالية

هذه مكتبة حسابية وليست خدمة API أو مهمة خلفية أو تكاملاً مع قاعدة البيانات.
لا تنفذ إعادة الشبكة (regridding)، ولا تستنتج أن النموذج المرجعي هو الحقيقة.
مقاييس التحقق من التوقعات تحتاج رصداً مستقلاً موثقاً؛ مقارنة نموذجين ببعضهما
لا تعادل التحقق من الدقة. حفظ النتائج وربطها بمعرفات الحقول في PostgreSQL
سيأتي ضمن تكامل الخدمة اللاحق.
