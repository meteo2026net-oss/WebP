# بوابة التحقق من بيانات أعضاء GEFS

تضيف هذه المرحلة فحصاً لملفات metadata الجانبية قبل تجميع أعضاء GEFS.

## ما الذي تتحقق منه؟
- أن كل ملف موسوم بأنه GEFS ومن مصدر NOAA/NCEP NOMADS.
- صلاحية معرف العضو وعدم تكراره.
- تطابق دورة التشغيل ووقت الصلاحية وساعة التنبؤ والدقة.
- تطابق المتغيرات والمستويات المطلوبة، مع تجاهل اختلاف ترتيبها.
- تطابق اسم ملف GRIB مع الاسم المذكور في sidecar.

## الحدود الحالية
هذه البوابة لا تفك GRIB ولا تثبت تطابق إحداثيات خطوط الطول والعرض أو وحدات القياس داخل الرسائل. لا يجوز تمرير الحقول إلى إحصاءات ensemble اعتماداً على تطابق sidecars وحده. يجب أن تتحقق مرحلة فك GRIB من إحداثيات الشبكة والوحدات والمتغير والمستوى والوقت داخل كل رسالة.

## الاستخدام

    from ecmwf_collector.gefs_grib import load_gefs_member_metadata
    metadata = load_gefs_member_metadata(["gefs_c00.grib2", "gefs_p01.grib2"])

تقرأ الدالة ملفات source.json المجاورة وتعيد mapping بحسب العضو إذا اجتازت شروط التجميع. الحد الأدنى الافتراضي عضوان.
